07 / Working style

How I work.

When someone reports a problem
I ask what they're trying to do and how urgent it is, check their identity if it involves access, then look into the issue, often with a remote tool. I fix what I can on the first contact, write the steps in the ticket and check with the user before I close it.
When I can't fix it
I escalate with clear notes and the steps I already tried, so the next team doesn't have to ask the user the same questions again.
When I'm learning something new
I start with the basic workflow, then test what happens when something goes wrong.
